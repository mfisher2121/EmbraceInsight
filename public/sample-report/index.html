SIX-GATE METHOD / ILLUSTRATIVE REPORT FORMAT

One page. One query. A documented verdict.

By Max Fisher · Illustrative format, not an issued certification · 2026-10-29

A completed clearance review evaluates one URL for one target query. This page describes the report format; it does not evaluate a live website or issue a certificate.

The inputs

URL, target query, location if relevant, scan timestamp, and a frozen set of semantic requirements.

The six-gate matrix

  • G0 — CrawlabilityCan search engines reach the actual page and its main content?
  • G1 — Index EligibilityCan the URL be indexed as itself, with consistent directives and identity?
  • G2 — Query AlignmentDoes the page type and subject match the query?
  • G3 — Semantic CoverageDoes every frozen question, section, and entity have evidence?
  • G4 — Citation MapDo verifiable claims link to supporting authority?
  • G5 — Trust SignalsIs the responsible publisher identified with contact and appropriate schema?

The finding

Each gate receives SG-PASS or SG-FAIL from its evidence. The first failed gate is the primary failure. Technical findings describe exact unmet requirements. A full PASS requires all six gates; missing evidence fails the relevant condition.

The boundary

Eligibility does not promise Google indexing or rankings. This independent method is separate from Google’s published technical requirements.

The current request form records a review request. It does not run an instant automated certification. No verdict is generated by this sample.
