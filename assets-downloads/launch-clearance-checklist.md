## Document and discovery

- [ ] Anonymous HTTP response contains the intended page.
- [ ] Main text, meaningful links, and resource content exist in initial HTML.
- [ ] robots.txt and sitemap.xml reflect the intended release audience and URL.
- [ ] Canonical, sitemap, structured identity, and social metadata use the actual intended origin.
- [ ] No accidental redirect or canonical points to an unrelated document.

## Indexing and page purpose

- [ ] HTML and HTTP indexing directives have been inspected.
- [ ] The title and one descriptive H1 fit the page's intended query.
- [ ] Required questions, sections, and entities have been frozen and checked.

## Evidence and responsibility

- [ ] Verifiable claims link to supporting primary or authoritative sources.
- [ ] Responsible publisher, contact route, and appropriate schema agree.
- [ ] Draft examples, mock data, and unverified claims are labeled.

## Forms and next steps

- [ ] Form success appears only after a durable write succeeds.
- [ ] Resource requests and newsletter opt-in are separate choices.
- [ ] Failure, duplicate-request, and unsubscribe paths have been tested.
- [ ] No email-delivery claim is made before the delivery path has been verified.
