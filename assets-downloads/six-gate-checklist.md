## G0 — Crawlability

- [ ] The anonymous request returns the actual page successfully, rather than a sign-in or error document.
- [ ] Main content is present in initial HTML.
- [ ] Crawl declarations and discovery paths are available and appropriate for this page.
- [ ] The redirect path and document identity are recorded.

## G1 — Index Eligibility

- [ ] Indexing directives are recorded from both HTML and response headers.
- [ ] Title, description, and canonical identity are present and consistent.
- [ ] No unintended noindex, canonical displacement, or other restriction prevents this URL from being indexed as itself.

## G2 — Query Alignment

- [ ] The page type addresses the target query's intent.
- [ ] Title and H1 clearly describe the page's subject.
- [ ] Required local context is present when the query is local.
- [ ] The relevant search-result snapshot and context are recorded.

## G3 — Semantic Coverage

- [ ] A finite list of required questions, sections, and entities is frozen before evaluation.
- [ ] Every requirement has exact page evidence.
- [ ] PAA questions come from a recorded snapshot or an explicitly identified operator list; none are invented.
- [ ] Missing evidence remains an unmet requirement.

## G4 — Citation Map

- [ ] Every verifiable claim that requires authority has an outbound supporting source link.
- [ ] The source supports the specific claim and is current for the relevant period.
- [ ] Mentions, internal links, and unsupported assumptions are not counted as authority citations.

## G5 — Trust Signals

- [ ] A responsible organization or author is identified.
- [ ] Contact information and appropriate structured data are consistent with visible content.
- [ ] Credentials and results are asserted only when supported.

## Record the outcome

Under this framework, every required condition needs evidence. Missing evidence fails the relevant gate. The first failed gate is the primary failure. A full PASS requires all six gates; no score or ranking probability is substituted.

Google's minimum technical requirements are a separate published standard. The six-gate framework is independent; eligibility does not promise indexing or ranking.
